# PazPlay

**Español:** PazPlay es un reproductor de listas IPTV (M3U y Xtream Codes) para Android, Android TV y Fire TV.
PazPlay es solo un reproductor: **no incluye ni vende canales, películas, series ni listas.**

**English:** PazPlay is an IPTV playlist player (M3U and Xtream Codes) for Android, Android TV and Fire TV.
PazPlay is only a player: **it does not include or sell any channels, movies, series or playlists.**

**Português:** PazPlay é um player de listas IPTV (M3U e Xtream Codes) para Android, Android TV e Fire TV.
PazPlay é apenas um player: **não inclui nem vende canais, filmes, séries ou listas.**
